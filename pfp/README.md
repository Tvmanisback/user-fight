# Fighter profile pictures

Add the three fighter avatar images to this folder using these exact filenames:

- `zeebers.png` — Zeebers (green)
- `calculated.png` — Calculated (red)
- `icob.png` — icob (blue)

Use square PNG images for best results. The game loads each image onto that fighter's 3D head. If an image is missing, the fighter uses the default plain head.
